# Проектная работа спринта 3 — цифровая трансформация банка «Стандарт»

Репозиторий содержит решения пяти заданий проектной работы курса «System Design Pro» (Яндекс Практикум).

| Директория | Задание | Артефакты |
|---|---|---|
| **Task1** | Карта IT-ландшафта и схема интеграции приложений | `IT-Landscape_Map.drawio` (карта: строки — оргструктура, колонки — бизнес-возможности 2-го уровня), `Integration_Scheme.drawio` (схема интеграции с участниками процессов), `README.md` (описание кредитного процесса и проблем ландшафта) |
| **Task2** | FURPS+ таблица | `FURPS_requirements.md` — требования MVP депозитного направления и кредитного направления + дополнительные требования с обоснованиями |
| **Task3** | Открытие депозитов онлайн (ADR) | `ADR_deposit_MVP.md`, диаграммы: `C4_context_deposit_MVP.png` (контекст), `C4_containers_deposit_MVP.png` (контейнеры; детализация интернет-банка и АБС), исходники `.puml` |
| **Task4** | Передача ставок в кол-центр (ADR + задачи + RoadMap) | `ADR_rates_to_callcenter.md`, диаграммы `C4_context_rates_callcenter.png` / `C4_components_rates_callcenter.png` (`.puml` рядом), `Tasks_by_system.md` (крупные задачи по системам, T1–T12), `RoadMap.drawio` (MVP 6 месяцев + целевое решение 12 месяцев) |
| **Task5** | Заявка на кредит онлайн (ADR) | `ADR_credit_online.md`, диаграммы `C4_context_credit_online.png` / `C4_components_credit_online.png` (`.puml` рядом) |

Сквозные архитектурные решения: единый источник ставок — справочник в АБС; онлайн-каналы интегрируются с ядром через сервисы-посредники (сервис интеграции депозитов, сервис кредитных заявок), а не напрямую с БД/API АБС; онлайн-заявки на кредит передаются в кредитный конвейер напрямую через API, минуя суточный обмен АБС ↔ конвейер; клиентские СМС — через существующий СМС-шлюз телеком-оператора из единой точки.
