# Задание 4. Крупные задачи по системам (для планирования)

Задачи разложены по системам из ADR «Передача ставок в кол-центры». Нумерация T1–T11 используется в RoadMap (`RoadMap.drawio`). Этапы: **MVP — месяцы 1–6**, **целевое решение — месяцы 7–12**.

## АБС (команда АБС)

- **T1. Справочник ставок в АБС + аудит изменений** (MVP): схема ставок, роли для бэк-офиса депозитов и кредитов с разграничением доступа, журнал изменений. Заменяет Excel-файлы.
- **T2. API депозитов АБС: выдача ставок, приём заявок, статусы** (MVP): REST-интерфейс над ядром АБС для сервиса интеграции.
- **T10. Автоматизация открытия депозита** (целевое): открытие депозита по подтверждённой заявке без участия бэк-офиса; публикация событий изменения статуса для сервиса интеграции.

## Сервис интеграции депозитов (команда АБС, Java)

- **T3. Разработка сервиса: кэш ставок, заявки интернет-банка, СМС-коды** (MVP): синхронизация ставок по API АБС, REST для интернет-банка и сайта, интеграция с СМС-шлюзом, передача лидов в систему кол-центра.
- **T4. API ставок для системы кол-центра** (MVP): REST выдачи публичных ставок со срезом кэша.
- **T5. Экспорт ставок в файл и SFTP-клиент** (MVP): формирование CSV при изменении справочника и по расписанию, выкладка на SFTP-сервер, версия и контрольная сумма.
- **T11. Автоматическая обработка заявок** (целевое): согласование ставки по правилам без бэк-офиса, сквозные статусы, персонализированные предложения онлайн.

## SFTP-сервер (IT-инфраструктура банка)

- **T6. Развернуть SFTP-сервер** (MVP): сервер в контуре банка, изолированный каталог партнёра (chroot) с доступом только на чтение, управление ключами, мониторинг выкладки, алертинг при отсутствии свежего файла.

## Система кол-центра (подрядчик платформы / Java-специалисты команды АБС)

- **T7. Интеграция с API ставок и вывод оператору** (MVP): периодический опрос API ставок, локальный кэш-срез с пометкой времени, отображение ставок в UI оператора, дообработка обращения по текущему процессу.

## Система партнёрского кол-центра (команда партнёра)

- **T8. Загрузка файлов со SFTP и вывод оператору** (MVP): периодическая загрузка файла со ставками, проверка версии и контрольной суммы, отображение ставок операторам. Формат файла и SLA фиксируются договором.

## Интернет-банк (команда банка + подрядчик платформы)

- **T9. UI депозитов в интернет-банке** (MVP): каталог с актуальными и персональными ставками, форма заявки (счёт, сумма), ввод СМС-кода, статус заявки. Без доработок ядра платформы.
- **T12. Автоматическое открытие депозита онлайн** (целевое): полный цифровой продукт — от заявки до открытого депозита без визита в отделение для действующих клиентов.

## Сайт (команда банка)

- В MVP сайта (входит в T3 как приём лидов): страница депозитов с публичными ставками и форма заявки (телефон, Ф. И. О.) с шифрованием трафика.

## Сквозные работы

- Интеграционное тестирование MVP (все системы), нагрузочное тестирование API АБС и сервиса интеграции, запуск MVP (конец месяца 6).
- Целевое состояние: сквозная автоматизация процесса (месяцы 7–12), регрессионное тестирование и запуск (месяц 12).
